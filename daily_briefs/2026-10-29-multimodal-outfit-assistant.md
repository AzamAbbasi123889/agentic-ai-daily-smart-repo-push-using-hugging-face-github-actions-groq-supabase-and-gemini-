# Multimodal Outfit Compatibility Assistant

> A privacy‑first web service that takes a user‑uploaded clothing image and a short occasion description, then recommends visually and contextually compatible items from a catalog using discrete visual token embeddings aligned with language. The MVP delivers a fast, token‑based similarity search and a concise style explanation.

**Date:** 2026-10-29 | **Category:** Computer Vision and Multimodal AI | **Difficulty:** Intermediate | **Effort:** 7 days

**Build-it-yourself brief:** this factory produces the specification, not source code.

## 1. Problem statement

Consumers struggle to envision complete outfits when only a single garment is at hand, leading to poor purchase decisions and increased returns. Existing recommendation tools either rely on heavyweight image embeddings or ignore textual context, making them slow or irrelevant for specific occasions.

### Target users

- Online fashion shoppers
- Retail catalog curators
- Style influencers

## 2. Unique angle

Leverages the recent research on discrete visual tokens as lossless representations, enabling a lightweight, token‑level vision‑language alignment that runs on CPU/GPU‑lite hardware while preserving semantic detail, unlike conventional dense embeddings.

## 3. MVP features and acceptance criteria

### Visual‑Token Catalog Indexing

Convert each catalog image into a sequence of discrete visual tokens and store the resulting embedding in pgvector.

- [ ] All catalog images processed without error
- [ ] Embedding vectors stored with <0.5 s per image
- [ ] Space overhead <2 × raw image size

### Multimodal Recommendation API

Accept an uploaded image and occasion text, compute its visual tokens and text embedding, perform a combined similarity search, and return top‑3 product IDs with a one‑sentence style rationale generated by a small LLM.

- [ ] API responds <1 s for 10 k catalog size
- [ ] Returned items share visual style and match occasion keyword
- [ ] Rationale contains both visual and textual cues

### React Frontend Demo

Simple UI to upload a photo, type occasion, view recommendations with product thumbnails and generated style text.

- [ ] Upload works across Chrome/Firefox
- [ ] Recommendations displayed within 2 s of submission
- [ ] No image persisted on server beyond request

## 5. Architecture

A client‑server app where the frontend streams user inputs to FastAPI, which orchestrates tokenization, embedding, vector search, and LLM reasoning before responding. All data resides in a single PostgreSQL instance with pgvector; Redis caches recent queries.

- **Frontend** — Collect image & text, display results

### Data flow

1. User uploads image & text → FastAPI receives request
2. → Image sent to Tokenization Service → Visual token vector returned
3. → Text sent to Transformer encoder → Text embedding returned
4. → Concatenate / weighted‑sum embeddings → Query pgvector → Top‑k product IDs
5. → Retrieve product metadata → Call Rationale Generator → Assemble response
6. → Response cached in Redis → Sent back to Frontend

## 6. Data model

- **product:** id (UUID), name (text), image_url (text), category (text), price (numeric), visual_vector (vector), text_embedding (vector), metadata_json (jsonb)
- **user_request:** id (UUID), timestamp (timestamptz), image_path (text), occasion_text (text), visual_vector (vector), text_embedding (vector), recommended_product_ids (uuid[]), rationale (text)
